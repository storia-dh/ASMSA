Schema da foglio di calcolo

Incolla il link CSV pubblicato della scheda Nodi (e, se lo usi, quello della scheda Impostazioni): lo schema si ridisegna da solo, resta aggiornato quando modifichi il foglio, ed è pronto da incorporare su una pagina web.

Sorgente dati

Per ottenere il link: nel foglio Google, apri la scheda "Nodi" → File → Condividi → Pubblica sul web → scegli il foglio "Nodi" (non "Intero documento") → formato CSV → Pubblica. Ripeti per "Impostazioni" se la usi.

Nessun dato caricato Incolla il link CSV della scheda "Nodi" qui sopra, oppure prova con i dati di esempio.

Incorpora questa pagina

Carica questo file HTML sul tuo sito, Google Drive pubblicato o GitHub Pages, poi incolla il suo indirizzo qui sotto per generare il codice da incorporare. Ricaricando la pagina di destinazione, lo schema si aggiorna da solo con i dati più recenti del foglio.
